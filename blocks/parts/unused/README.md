# Unused Parts

This directory records parts listed as unused on the Road to Gramby's Wiki. These entries are wiki-notes and do not imply the parts exist in the active save-format; consult `old-files/obj_ids-spanish.md` for historical mentions.
See [`parts/unused/parts-id.md`](parts/unused/parts-id.md) for the consolidated Part ID reference.

Notes
