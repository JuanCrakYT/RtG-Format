# Tools / Weapons

This directory contains tool and weapon parts as categorized by the Road to Gramby's Wiki and cross-checked with `old-files/obj_ids-spanish.md`.
See [`parts/tools/parts-id.md`](parts/tools/parts-id.md) for the consolidated Part ID reference.

What this contains
- Tables for items with documented connection IDs (e.g., `Uzi`, `Briefcase`).
- An index of tool items with notes about historical verification and special behaviors.

Notes
- Do not treat wiki classification as proof of format IDs. Historical evidence is preserved and annotated.
- New documentation indicates: RtG uses 1-based indexing for references.
