# Physics Parts

This directory contains parts classified as "Physics" by the Road to Gramby's Wiki and the historical extraction in `old-files/obj_ids-spanish.md`.

What this contains
- Per-part connection-point tables extracted from `old-files/obj_ids-spanish.md` when present.
- A category index summarizing which items the historical file documents with detailed tables vs. which are only mentioned.

Sources
- Reverse-engineering data: `old-files/obj_ids-spanish.md` (preserved unchanged).
- Game/wiki classification: Road to Gramby's public wiki (used for organization only).

Important notes
- Wiki information is for classification/context only and is not treated as proof of internal save-format behavior.
- Historical data is preserved exactly as found; do not assume wiki numbers map to format IDs.
- Documentation in this directory states that RtG uses 1-based indexing for references.
