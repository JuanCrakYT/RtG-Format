# old-files

This folder contains auxiliary files and documentation in **Spanish** related to the **RtG-Format** project.

Its contents may include notes, documentation, references, research, translations, work-in-progress versions, and other files used during the development and research of the **Road To Gramby's (RtG)** save format.

## Purpose

The files in this folder are primarily intended to serve as reference and supporting material for the research and documentation of the project.
The contents of `old-files/` **do not necessarily form part of the official documentation or always represent the current state of the format**. For current and confirmed information, the main documentation of the repository should be consulted.

## Language

The files in this folder are primarily written in **Spanish**.
The official documentation of the project may use another language when necessary.

## Maintenance

`old-files/` is a folder maintained by the creator of the repository, **JuanCrakYT**.

The files in this folder **are not intended to be modified by external contributors**. Any changes, corrections, deletions, or additions of files within this folder are at the discretion of **JuanCrakYT**.

Contributions to the rest of the repository may follow the normal process established by the project.

## Important

The presence of a file within `old-files/` does not imply that the information contained within it is correct, definitive, or current.
When there is a discrepancy between `old-files/` and the current official documentation, **the documentation in `old-files/` takes priority**.
