# Security Policy

## Scope

RtG-Format is an independent research, documentation, and tooling project. Security reports are most relevant when they concern a vulnerability in code maintained in this repository, unsafe handling of untrusted save/build files, unintended data exposure, or a compromised project release or deployment.

The repository documents a third-party game's save/build format and is not affiliated with or endorsed by the game's creators.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or a weaponized proof of concept in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository maintainer through the contact method listed on the maintainer's GitHub profile and include:

- A concise description of the issue and its potential impact.
- The affected file, component, version, or commit.
- Reproduction steps and a minimal, non-sensitive proof of concept.
- Any suggested mitigation, if known.

Do not include real credentials, private save data, or other sensitive information in a report.

## Response expectations

The maintainer will assess reports as time and availability permit. No response-time or remediation-time guarantee is made. Please allow a reasonable opportunity to investigate and address a confirmed issue before publicly disclosing technical details.

## Supported versions

Unless a release-specific support policy is published, assume that security fixes are evaluated against the current default branch. Older snapshots may no longer receive fixes.
