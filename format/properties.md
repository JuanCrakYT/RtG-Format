# Properties

Purpose
- Collect known properties, their types, examples and confidence levels.

Guideline
- Each property entry should contain: Name, Type, Example, Observed in (file/experiment), Confidence.

Initial confirmed examples (from historical research):
- `RGB`: Array `[R,G,B]` — Example: `[255,0,0]` — Observed in many Parts/SprayPaint — CONFIRMED.
- `EphemeralAttachments`: Object mapping UUID -> {partName, cframe} — CONFIRMED.

Do not add properties without evidence. Use `research/experiments.md` to store test procedures used to confirm properties.
