Uso: rtg [-v | --version] [-language <idioma>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <comando> [<args>]

Los comandos de rtg más utilizados son:
  image       | Convertidor de imágenes impulsado por: "RtG Image".
  preview     | Abre un HTML para ver la construcción JSON de Road to Gramby's
  --commands | Muestra una lista de los comandos internos de rtg
  --addons    | Muestra los addons disponibles con documentación

Usa 'rtg help <comando> [<idioma>]' para más información sobre un comando específico.
Usa 'rtg help <comando> -lang' para ver los idiomas de ese addon.
Usa 'rtg --commands' para ver los comandos internos actuales.
Usa 'rtg --addons' para ver los addons disponibles.
