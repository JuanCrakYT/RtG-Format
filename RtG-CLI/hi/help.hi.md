RtG-CLI — मदद
===============

RtG-CLI RtG-Format पारिस्थितिकी तंत्र का कमांड-लाइन इंटरफेस है।
यह एडऑन की खोज और निष्पादन, भाषा क्वेरी, नियम और संस्करण देखने की अनुमति देता है।

उपयोग
-------

  rtg [विकल्प] <कमांड> [आर्गुमेंट]

  पहला आर्गुमेंट निष्पादित करने वाले कमांड या एडऑन की पहचान करता है।

  उदाहरण:
    rtg image
    rtg preview
    rtg help image


सिस्टम कमांड
---------------

  -h, --help        यह सामान्य मदद प्रदर्शित करता है
  -v, --version     RtG-CLI संस्करण प्रदर्शित करता है
  -l, --lang        RtG-CLI में उपलब्ध भाषाओं को सूचीबद्ध करता है
  -r, --rules       RtG-CLI नियम प्रदर्शित करता है
  -c, --commands    RtG-CLI आंतरिक कमांड सूचीबद्ध करता है
  -a, --addons      उपयोगकर्ता-दृश्य दस्तावेज़ीकरण वाले एडऑन सूचीबद्ध करता है
  -language <भाषा>   स्टार्टअप टेक्स्ट (void) की भाषा सेट करता है

कमांड: help
---------------

  rtg help                    # सामान्य मदद (यह स्क्रीन)
  rtg help <कमांड>           # विशिष्ट कमांड/एडऑन के लिए मदद
  rtg help <कमांड> -<भाषा>     # विशिष्ट भाषा में मदद (उदाहरण: -es, -en)
  rtg help <कमांड> -lang       # उस कमांड के लिए उपलब्ध भाषाएं

  उदाहरण:
    rtg help image
    rtg help image -en
    rtg help image -lang


कमांड: version
-----------------

  rtg -v
  rtg --version

  संस्करण और सभी उपलब्ध भाषाओं में संस्करण सामग्री प्रदर्शित करता है।


कमांड: rules
---------------

  rtg -r
  rtg --rules
  rtg -r -<भाषा>   # विशिष्ट भाषा में नियम (उदाहरण: rtg -r -en)

  डिफ़ॉल्ट रूप से 'rules' में परिभाषित पहली भाषा (स्पेनिश) का उपयोग करता है।


कमांड: lang
---------------

  rtg -l
  rtg --lang

  सभी उपलब्ध भाषाओं को श्रेणी के अनुसार सूचीबद्ध करता है:
  Version, Rules, Help, Void, और प्रति एडऑन।


कमांड: commands
--------------------

  rtg -c
  rtg --commands

  केवल RtG-CLI आंतरिक कमांड सूचीबद्ध करता है।
  इसमें एडऑन कमांड शामिल नहीं हैं।


कमांड: addons
----------------

  rtg -a
  rtg --addons

  उन एडऑन को सूचीबद्ध करता है जिनके पास उपयोगकर्ता-दृश्य दस्तावेज़ीकरण/मदद है।
  दस्तावेज़ीकरण के बिना पंजीकृत एडऑन यहां दिखाई नहीं देता।


कमांड: language
-------------------

  rtg -language <भाषा>

  स्टार्टअप टेक्स्ट (void) की भाषा चुनता है।
  भाषा assets.json के 'void-language' में मौजूद होनी चाहिए।

  उदाहरण:
    rtg -language en


उपलब्ध एडऑन
-----------------

  image      | RtG Image        - छवि कनवर्टर
  preview    | RtG Preview      - RtG-Format बिल्ड के लिए 3D व्यूअर
  test-addon | RtG Test Addon   - CLI सत्यापन के लिए टेस्ट एडऑन


भाषाएं
---------

भाषाएं एकल हाइफ़न से दर्शाई जाती हैं: -es, -en, -pt आदि।
भाषा आंतरिक कमांड नाम नहीं बदलती।

  rtg help image -es    # स्पेनिश मदद
  rtg help image -en    # अंग्रेजी मदद
  rtg -r -en            # अंग्रेजी नियम

  किसी एडऑन की भाषाएं देखने के लिए:
    rtg help image -lang

  -lang का अर्थ इसकी स्थिति पर निर्भर करता है:
    rtg --lang          # RtG-CLI भाषाएं (एडऑन से पहले)
    rtg image -lang     # एडऑन भाषाएं (एडऑन के बाद)


एडऑन आर्गुमेंट
-----------------

एडऑन की पहचान के बाद, आर्गुमेंट्स को प्रीफिक्स द्वारा वर्गीकृत किया जाता है:

  बिना हाइफ़न       -> एडऑन        (उदाहरण: convert, file.png)
  --विकल्प          -> एडऑन        (उदाहरण: --width 128)
  -विकल्प           -> RtG-CLI      (उदाहरण: -lang, -en)

उदाहरण:
  rtg image convert file.png     # convert, file.png -> एडऑन
  rtg image --width 128          # --width 128 -> एडऑन
  rtg image -lang                # -lang -> RtG-CLI (एडऑन भाषाएं)
  rtg image -en                  # -en -> RtG-CLI (भाषा चयनकर्ता)


स्पेस वाले आर्गुमेंट
---------------------

स्पेस वाले आर्गुमेंट्स को उद्धरण चिह्नों में लिखा जाना चाहिए:

  rtg image "my image.png" "output.json"

RtG-CLI आर्गुमेंट क्रम को संरक्षित करता है और उन्हें एडऑन को वैसे ही पास करता है।


अधिक जानकारी
----------------

  rtg help <कमांड>      # एडऑन की विस्तृत मदद
  rtg help <कमांड> -lang  # उस एडऑन की भाषाएं
  rtg --addons          # सभी दस्तावेज़ीकृत एडऑन देखें
  rtg --commands        # आंतरिक कमांड देखें
