Användning: rtg [-v | --version] [-language <språk>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <kommando> [<args>]

De mest använda rtg-kommandona:
  image      | Bildkonverterare powered by: "RtG Image".
  preview    | Öppnar en HTML för att visa Road to Gramby's JSON-build
  --commands | Visar en lista över interna rtg-kommandon
  --addons   | Visar tillgängliga tillägg med dokumentation

Använd 'rtg help <kommando> [<språk>'] för mer information om ett specifikt kommando.
Använd 'rtg help <kommando> -lang' för att se språken för det tillägget.
Använd 'rtg --commands' för att se de faktiska interna kommandona.
Använd 'rtg --addons' för att se tillgängliga tillägg.
