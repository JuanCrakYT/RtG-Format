用法：rtg [-v | --version] [-language <语言>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <命令> [<参数>]

最常用的 rtg 命令：
  image      | 图像转换器 powered by: "RtG Image"。
  preview    | 打开 HTML 查看 Road to Gramby's JSON 构建
  --commands |命令列表
  --addons   | 显示带文档的可用插件

使用 'rtg help <命令> [<语言>]' 获取特定命令的更多信息。
使用 'rtg help <命令> -lang' 查看该插件的语言。
使用 'rtg --commands' 查看实际内部命令。
使用 'rtg --addons' 查看可用插件。
