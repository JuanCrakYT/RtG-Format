Usage: rtg [-v | --version] [-language <language>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <command> [<args>]

The most commonly used rtg commands are:
  image      | Image converter powered by: "RtG Image".
  preview    | Opens an HTML to view Road to Gramby's JSON build
  --commands | Show a list of the rtg internal commands
  --addons   | Show available addons with documentation

Use 'rtg help <command> [<language>]' for more information on a specific command.
Use 'rtg help <command> -lang' to see the languages of that addon.
Use 'rtg --commands' to see the actual internal commands.
Use 'rtg --addons' to see available addons.
