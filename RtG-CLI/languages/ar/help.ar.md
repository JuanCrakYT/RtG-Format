RtG-CLI — المساعدة
====================

RtG-CLI هو واجهة سطر أوامر نظام RtG-Format البيئي.
يسمح باكتشاف وتنفيذ الإضافات، والاستعلام عن اللغات، وعرض القواعد والإصدار.

الاستخدام
-----------

  rtg [خيارات] <أمر> [وسيطات]

  أول وسيطة تحدد الأمر أو الإضافة المراد تنفيذها.

  أمثلة:
    rtg image
    rtg preview
    rtg help image


أوامر النظام
---------------

  -h, --help        يعرض هذه المساعدة العامة
  -v, --version     يعرض إصدار RtG-CLI
  -l, --lang        يسرد اللغات المتاحة في RtG-CLI
  -r, --rules       يعرض قواعد RtG-CLI
  -c, --commands    يسرد أوامر RtG-CLI الداخلية
  -a, --addons      يسرد الإضافات التي لها وثائق مرئية للمستخدم
  -u, --usage       يعرض معلومات الاستخدام الشائعة (جديد)
  -u-<لغة>           يعرض الاستخدام بلغة محددة (مثال: -u-es, -u-en) (جديد)
  --usage-<لغة>       يعرض الاستخدام بلغة محددة (مثال: --usage-es, --usage-en) (جديد)
  -language <لغة>     يحدد لغة نص البدء (void)

أمر: help
-------------

  rtg help                    # مساعدة عامة (هذه الشاشة)
  rtg help <أمر>              # مساعدة لأمر/إضافة محددة
  rtg help <أمر> -<لغة>        # مساعدة بلغة محددة (مثال: -es, -en)
  rtg help <أمر> -lang         # اللغات المتاحة لذلك الأمر
  rtg help -u                  # مساعدة عامة (جديد)
  rtg help -u-<لغة>            # مساعدة بلغة محددة (مثال: -u-es) (جديد)
  rtg help --usage             # مساعدة عامة (جديد)
  rtg help --usage-<لغة>        # مساعدة بلغة محددة (مثال: --usage-es) (جديد)
  rtg help usage               # مساعدة عامة (بناء جملة بديل، جديد)

  أمثلة:
    rtg help image
    rtg help image -en
    rtg help image -lang
    rtg help -u
    rtg help -u-en
    rtg help --usage-es


أمر: version
---------------

  rtg -v
  rtg --version

  يعرض الإصدار ومحتوى الإصدار بجميع اللغات المتاحة.


أمر: rules
--------------

  rtg -r
  rtg --rules
  rtg -r -<لغة>   # قواعد بلغة محددة (مثال: rtg -r -en)

  افتراضياً يستخدم أول لغة معرفة في 'rules' (الإسبانية).


أمر: lang
-------------

  rtg -l
  rtg --lang

  يسرد جميع اللغات المتاحة منظمة حسب الفئة:
  Version, Rules, Help, Void، وكل إضافة.


أمر: commands
----------------

  rtg -c
  rtg --commands

  يسرد أوامر RtG-CLI الداخلية حصرياً.
  لا يتضمن أوامر الإضافات.


أمر: addons
--------------

  rtg -a
  rtg --addons

  يسرد الإضافات التي لديها وثائق/مساعدة مرئية للمستخدم.
  إضافة مسجلة بدون وثائق لا تظهر هنا.


أمر: usage
--------------

  rtg -u
  rtg --usage
  rtg -u-<لغة>           # استخدام بلغة محددة (مثال: -u-es, -u-en) (جديد)
  --usage-<لغة>           يعرض الاستخدام بلغة محددة (مثال: --usage-es, --usage-en) (جديد)

  يعرض معلومات الاستخدام الشائعة (void) باللغة المطلوبة.
  يجب أن توجد اللغة في 'void-language' في assets.json.


أمر: language
-----------------

  rtg -language <لغة>

  يحدد لغة نص البدء (void).
  يجب أن توجد اللغة في 'void-language' في assets.json.

  مثال:
    rtg -language en


الإضافات المتاحة
-------------------

  image      | RtG Image        - محول الصور
  preview    | RtG Preview      - عارض 3D لبنيات RtG-Format
  test-addon | RtG Test Addon   - إضافة اختبار لتحقق CLI


اللغات
---------

يتم تحديد اللغات بشرطة واحدة: -es, -en, -pt إلخ.
اللغة لا تغير اسم الأمر الداخلي.

  rtg help image -es    # مساعدة بالإسبانية
  rtg help image -en    # مساعدة بالإنجليزية
  rtg -r -en            # قواعد بالإنجليزية

  لعرض لغات إضافة:
    rtg help image -lang

  معنى -lang يعتمد على موضعه:
    rtg --lang          # لغات RtG-CLI (قبل الإضافة)
    rtg image -lang     # لغات الإضافة (بعد الإضافة)


وسيطات الإضافات
------------------

بعد تحديد إضافة، يتم تصنيف الوسيطات حسب البادئة:

  بدون شرطة       -> إضافة        (مثال: convert, file.png)
  --خيار          -> إضافة        (مثال: --width 128)
  -خيار           -> RtG-CLI      (مثال: -lang, -en)

أمثلة:
  rtg image convert file.png     # convert, file.png -> إضافة
  rtg image --width 128          # --width 128 -> إضافة
  rtg image -lang                # -lang -> RtG-CLI (لغات الإضافة)
  rtg image -en                  # -en -> RtG-CLI (منتقي اللغة)


وسيطات بمسافات
-----------------

الوسيطات التي تحتوي مسافات يجب أن تكون بين اقتباسات:

  rtg image "my image.png" "output.json"

RtG-CLI يحافظ على ترتيب الوسيطات ويمررها كما هي للإضافة.


مزيد من المعلومات
--------------------

  rtg help <أمر>      # مساعدة تفصيلية لإضافة
  rtg help <أمر> -lang  # لغات تلك الإضافة
  rtg --addons        # عرض جميع الإضافات الموثقة
  rtg --commands      # عرض الأوامر الداخلية
