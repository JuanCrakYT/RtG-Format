用法：rtg [-v | --version] [-language <語言>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <指令> [<參數>]

最常用的 rtg 指令：
  image      | 影像轉換器 powered by: "RtG Image"。
  preview    | 開啟 HTML 檢視 Road to Gramby's JSON 建構
  --commands |rtg 內部指令列表
  --addons   | 顯示帶文件的可用外掛

使用 'rtg help <指令> [<語言>]' 取得特定指令的更多資訊。
使用 'rtg help <指令> -lang' 檢視該外掛的語言。
使用 'rtg --commands' 檢視實際內部指令。
使用 'rtg --addons' 檢視可用外掛。
