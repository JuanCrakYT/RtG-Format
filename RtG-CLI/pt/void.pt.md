Uso: rtg [-v | --version] [-language <idioma>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <comando> [<args>]

Os comandos rtg mais usados são:
  image      | Conversor de imagens powered by: "RtG Image".
  preview    | Abre um HTML para ver a build JSON de Road to Gramby's
  --commands | uma lista dos comandos internos do rtg
  --addons   | Mostra addons disponíveis com documentação

Use 'rtg help <comando> [<idioma>]' para mais informações sobre um comando específico.
Use 'rtg help <comando> -lang' para ver os idiomas desse addon.
Use 'rtg --commands' para ver os comandos internos atuais.
Use 'rtg --addons' para ver os addons disponíveis.
