사용법: rtg [-v | --version] [-language <언어>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <명령어> [<인수>]

가장 자주 사용되는 rtg 명령어:
  image      | 이미지 변환기 powered by: "RtG Image".
  preview    | Road to Gramby's JSON 빌드를 보기 위한 HTML 열기
  --commands | rtg 내부 명령어 목록 표시
  --addons   | 문서가 있는 사용 가능한 애드온 표시

'rtg help <명령어> [<언어>]'를 사용하여 특정 명령어에 대한 자세한 정보 얻기.
'rtg help <명령어> -lang'을 사용하여 해당 애드온의 언어 보기.
'rtg --commands'를 사용하여 실제 내부 명령어 보기.
'rtg --addons'를 사용하여 사용 가능한 애드온 보기.
