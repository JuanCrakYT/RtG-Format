Verwendung: rtg [-v | --version] [-language <sprache>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <befehl> [<args>]

Die häufigsten rtg-Befehle sind:
  image      | Bildkonverter powered by: "RtG Image".
  preview    | Öffnet ein HTML zum Anzeigen der Road to Gramby's JSON-Build
  --commands | Zeigt eine Liste der internen rtg-Befehle
  --addons   | Zeigt verfügbare Addons mit Dokumentation

Verwenden Sie 'rtg help <befehl> [<sprache>]' für weitere Informationen zu einem bestimmten Befehl.
Verwenden Sie 'rtg help <befehl> -lang' um die Sprachen dieses Addons anzuzeigen.
Verwenden Sie 'rtg --commands' um die aktuellen internen Befehle anzuzeigen.
Verwenden Sie 'rtg --addons' um verfügbare Addons anzuzeigen.
