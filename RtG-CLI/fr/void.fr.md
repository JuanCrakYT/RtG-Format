Utilisation : rtg [-v | --version] [-language <langue>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <commande> [<args>]

Les commandes rtg les plus utilisées sont :
  image      | Convertisseur d'images powered by: "RtG Image".
  preview    | Ouvre un HTML pour voir la construction JSON de Road to Gramby's
  --commands | Affiche la liste des commandes internes rtg
  --addons   | Affiche les addons disponibles avec documentation

Utilisez 'rtg help <commande> [<langue>]' pour plus d'informations sur une commande spécifique.
Utilisez 'rtg help <commande> -lang' pour voir les langues de cet addon.
Utilisez 'rtg --commands' pour voir les commandes internes actuelles.
Utilisez 'rtg --addons' pour voir les addons disponibles.
