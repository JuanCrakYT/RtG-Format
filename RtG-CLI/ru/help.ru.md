RtG-CLI — Помощь
=================

RtG-CLI — интерфейс командной строки для экосистемы RtG-Format.
Позволяет обнаруживать и выполнять аддоны, запрашивать языки, просматривать правила и версию.

Использование
--------------

  rtg [ОПЦИИ] <КОМАНДА> [АРГУМЕНТЫ]

  Первый аргумент определяет команду или аддон для выполнения.

  Примеры:
    rtg image
    rtg preview
    rtg help image


Системные команды
------------------

  -h, --help        Показывает эту общую справку
  -v, --version     Показывает версию RtG-CLI
  -l, --lang        Показывает доступные языки в RtG-CLI
  -r, --rules       Показывает правила RtG-CLI
  -c, --commands    Показывает внутренние команды RtG-CLI
  -a, --addons      Показывает аддоны с документацией для пользователя
  -language <язык>    Устанавливает язык стартового текста (void)

Команда: help
--------------

  rtg help                    # Общая справка (этот экран)
  rtg help <команда>          # Справка для конкретной команды/аддона
  rtg help <команда> -<язык>  # Справка на конкретном языке (напр. -es, -en)
  rtg help <команда> -lang      # Доступные языки для этой команды

  Примеры:
    rtg help image
    rtg help image -en
    rtg help image -lang


Команда: version
-----------------

  rtg -v
  rtg --version

  Показывает версию и содержимое версии на всех доступных языках.


Команда: rules
---------------

  rtg -r
  rtg --rules
  rtg -r -<язык>   # Правила на конкретном языке (напр. rtg -r -en)

  По умолчанию используется первый язык, определенный в 'rules' (испанский).


Команда: lang
--------------

  rtg -l
  rtg --lang

  Показывает все доступные языки, организованные по категориям:
  Version, Rules, Help, Void, и по каждому аддону.


Команда: commands
------------------

  rtg -c
  rtg --commands

  Показывает исключительно внутренние команды RtG-CLI.
  Не включает команды аддонов.


Команда: addons
----------------

  rtg -a
  rtg --addons

  Показывает аддоны, имеющие документацию/помощь, видимую для пользователя.
  Зарегистрированный аддон без документации не появляется здесь.


Команда: language
------------------

  rtg -language <язык>

  Выбирает язык стартового текста (void).
  Язык должен существовать в 'void-language' в assets.json.

  Пример:
    rtg -language en


Доступные аддоны
-----------------

  image      | RtG Image        - Конвертер изображений
  preview    | RtG Preview      - 3D-просмотрщик сборок RtG-Format
  test-addon | RtG Test Addon   - Тестовый аддон для валидации


Языки
------

Языки указываются с одним дефисом: -es, -en, -pt, etc.
Язык не меняет внутреннее имя команды.

  rtg help image -es    # Справка на испанском
  rtg help image -en    # Справка на английском
  rtg -r -en            # Правила на английском

  Для просмотра языков аддона:
    rtg help image -lang

  Значение -lang зависит от его позиции:
    rtg --lang          # Языки RtG-CLI (до аддона)
    rtg image -lang     # Языки аддона (после аддона)


Аргументы аддонов
------------------

После идентификации аддона аргументы классифицируются по префиксу:

  без дефиса      -> аддон        (напр. convert, файл.png)
  --опция         -> аддон        (напр. --width 128)
  -опция          -> RtG-CLI      (напр. -lang, -en)

Примеры:
  rtg image convert файл.png     # convert, файл.png -> аддон
  rtg image --width 128          # --width 128 -> аддон
  rtg image -lang                # -lang -> RtG-CLI (языки аддона)
  rtg image -en                  # -en -> RtG-CLI (селектор языка)


Аргументы с пробелами
----------------------

Аргументы с пробелами должны быть в кавычках:

  rtg image "мой файл.png" "выход.json"

RtG-CLI сохраняет порядок и передает аргументы как есть аддону.


Дополнительная информация
--------------------------

  rtg help <команда>      # Подробная справка аддона
  rtg help <команда> -lang  # Языки этого аддона
  rtg --addons            # Все документированные аддоны
  rtg --commands          # Внутренние команды
