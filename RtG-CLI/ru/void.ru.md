Использование: rtg [-v | --version] [-language <язык>] [-h | --help] [-l | --lang] [-r | --rules] [-c | --commands] [-a | --addons] <команда> [<args>]

Самые часто используемые команды rtg:
  image      | Конвертер изображений powered by: "RtG Image".
  preview    | Открывает HTML для просмотра JSON-сборки Road to Gramby's
  --commands |азывает список внутренних команд rtg
  --addons   | Показывает доступные аддоны с документацией

Используйте 'rtg help <команда> [<язык>]' для получения информации о конкретной команде.
Используйте 'rtg help <команда> -lang' чтобы увидеть языки этого аддона.
Используйте 'rtg --commands' чтобы увидеть текущие внутренние команды.
Используйте 'rtg --addons' чтобы увидеть доступные аддоны.
