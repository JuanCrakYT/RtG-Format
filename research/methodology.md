# Methodology

Suggested reproducible steps for reverse-engineering saves

1. Create minimal build in-game.
2. Export save / capture raw JSON.
3. Modify a single field, re-import and observe effects.
4. Use color/visual markers to map connection point IDs (as described in `old-files/obj_ids-spanish.md`).
5. Record each experiment with Input, Procedure, Observation, Result, Confidence.

Always include raw save diffs when claiming a confirmation.
