# Json Examples

This folder is intended to hold real save examples and curated minimal builds for tests and demonstrations.

Rules
- Do NOT create or add fabricated saves. Only include JSON files with provenance and evidence.
- If an example can't be loaded, delete the example folder
- All the examples need a folder on `examples/json-examples/` with this structure:
```tree
<name>/
│
├── README.md
├── example.json (no notes, add notes on `README.md`)
└── images-videos/
    ├── presentation.png
    └── ...
```

## Undocumented Builds
The undocumented builds are a collection of JSON files that have been extracted from Roblox games and are not officially documented. 
These builds may contain unique features, structures, or configurations that are not commonly found in standard builds.

This is the path to the folder containing the undocumented builds:
```text
tools\RtG-AI\dev\json
```
This undocumented builds folder is from RtG-AI, a tool that extracts JSON builds from RtG and use them for AI training, analysis and create RtG builds.
The builds in this folder may not have been officially released or documented by the developers, but they can provide valuable insights into the inner workings of the game and its mechanics.

> **Note:** Some of RtG-AI JSON builds (tools\RtG-AI\dev\json) aren't of RtG-Format, and maybe be stolen from some social media platforms.
