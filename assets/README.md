# Assets

This directory contains visual assets used by the RtG-Format project, including the project's branding and documentation images.

## Images

The [`images/`](images/) directory contains the visual assets used throughout the repository.

### Documentation Banner

[`images/banner.svg`](images/banner.svg) — Current banner used by the main project documentation, including the root [`README.md`](../README.md).

### Current Project Logo

The current RtG-Format logo is maintained under [`images/initial-assets/logo/`](images/initial-assets/logo/).

* [`images/initial-assets/logo/RtG-Format.svg`](images/initial-assets/logo/RtG-Format.svg) — Current full RtG-Format logo.
* [`images/initial-assets/logo/RtG-Format-Shape.svg`](images/initial-assets/logo/RtG-Format-Shape.svg) — Current logo shape/isotype without the full wordmark.

These are the current official branding assets for the project.

### Obsolete Logo Versions

[`images/initial-assets/logo/v1/`](images/initial-assets/logo/v1/) contains obsolete versions of the RtG-Format logo.

The files in this directory are preserved for historical reference only and should **not** be used for new project materials or branding.

* [`RtG-Format-v1.svg`](images/initial-assets/logo/v1/RtG-Format-v1.svg) — Obsolete vector version.
* [`RtG-Format-v1.png`](images/initial-assets/logo/v1/RtG-Format-v1.png) — Obsolete raster version.

## Asset Guidelines

When adding new project assets:

* Keep visual assets inside [`images/`](images/).
* Keep current logo assets inside [`images/initial-assets/logo/`](images/initial-assets/logo/).
* Do not use assets from `logo/v1/` for new project materials; they are obsolete.
* Prefer SVG for logos and other graphics that need to scale cleanly.
* Use raster formats such as PNG when a raster version is specifically required.
* When replacing a project asset, preserve obsolete versions when they are useful for historical reference rather than silently presenting them as current assets.
