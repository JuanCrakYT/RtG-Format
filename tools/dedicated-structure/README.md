# Dedicated Structure

This directory contains complete tree listings for tool directories that are too large to expand in the repository-level [`structure.md`](../../structure.md).

## Files

- [`RtG-Image.tree`](RtG-Image.tree) - Complete tree for the `RtG Image/` tool directory.

## Listing rule

Tool directories with more than 10 entries are represented by `...` in `structure.md` and documented here with a dedicated `.tree` file named after the directory. Smaller directories remain expanded in `structure.md`.
