# Tools

This directory contains utilities used to inspect, convert, generate, and maintain RtG-Format data.

## Tool directories

### `RtG Image/`

Desktop utility for creating pixel-art images and converting them to RtG image data.
Its complete directory tree is documented in [`dedicated-structure/RtG-Image.tree`](dedicated-structure/RtG-Image.tree) because the directory contains more than 10 entries.

### `agent/`

Repository-maintenance scripts and migration data. See [`agent/README.md`](agent/README.md) for details.

## Directory structure documentation

Directories with more than 10 entries are abbreviated as `...` in the repository-level [`structure.md`](../structure.md). Their complete trees are stored in [`dedicated-structure/`](dedicated-structure/).

Directories with 10 or fewer entries may be expanded directly in `structure.md`.
