# FAQ

Q: What is this repository?
A: A documented consolidation of reverse-engineering work on RtG saves. It collects confirmed facts, experiments, and open research.

Q: Is everything in `old-files/` authoritative?
A: No. Historical files are preserved for provenance. Use `SPECIFICATION.md` and files under `format/` for the current reference.

Q: Can I add example JSON files?
A: Yes, but only with provenance. Do not create fabricated saves.
